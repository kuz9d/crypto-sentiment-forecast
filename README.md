## План работы

### 1. Сбор и анализ данных (октябрь 2026)

- Сбор OHLCV-котировок BTC и ETH (Binance / Bybit, CoinGecko), запрос исторических данных у бирж и дата-провайдеров
- Сбор новостей и постов из Reddit
- Очистка данных, синхронизация рядов по времени, обработка пропусков и аномалий
- Разведочный анализ: распределение доходностей, тяжёлые хвосты, кластеризация волатильности, стационарность (ADF, KPSS), автокорреляции (ACF / PACF), корреляции между активами, сезонность
- Выбор целевой переменной (цена / доходность / направление движения) и горизонта прогноза

### 2. Базовые модели (ноябрь 2026)

- Выбор метрик под постановку задачи
- Бейзлайны: наивный прогноз, скользящее среднее, ARIMA
- Признаки технического анализа: лаги доходностей, RSI, MACD, Bollinger Bands, ATR, объёмы
- Классический ML: линейные модели, Random Forest, градиентный бустинг (CatBoost / LightGBM)
- Walk-forward валидация, подбор гиперпараметров

### 3. ML-сервис (декабрь 2026)

- Сервис на FastAPI: приём истории котировок, инференс модели, возврат прогноза
- Валидация входных данных, Docker, тесты

### 4. Улучшение модели (февраль — март 2027)

- Текстовые признаки: сентимент новостей и соцсетей, агрегация по временным окнам
- Сравнение источников сигналов: технический анализ, новости, соцсети
- Расширение и очистка данных, новые признаки, ансамбли моделей

### 5. Нейронные сети (апрель — май 2027)

- LSTM / GRU, TCN
- Трансформеры для временных рядов: PatchTST, Temporal Fusion Transformer
- Мультимодальная модель: ценовой ряд и текстовые признаки
- Сравнение нейросетевых подходов с классическим ML

### 6. Финализация (май — июнь 2027)

- Логирование экспериментов и артефактов в MLflow, воспроизводимость
- Переобучение и сохранение лучшей модели
- Анализ ошибок и устойчивости модели в разных рыночных режимах
- Бэктест простой торговой стратегии на прогнозах с учётом комиссий
- Подготовка итогового отчёта и презентации
